# HR-30 protection and conductor architecture P0.1

**PRELIMINARY - PROTECTION AND CONDUCTOR ARCHITECTURE ONLY - NOT APPROVED FOR PROCUREMENT, CONNECTION, POWERED TESTING, MOTION OR ENERGIZATION**

This package separates the 5 V logic-only state from the 12 V actuator path and binds the latter through one source, dual interruption, five protected feeds and 25 eFuse branches. It deliberately releases no fuse value or conductor ampacity. Open [index.html](index.html) for the interactive guide.
