# HR-30 full-scale fit-check P0.1

**PRELIMINARY - 1:1 NONSTRUCTURAL FIT ARTICLES ONLY - NOT APPROVED FOR LOAD BEARING, STANDING, WALKING, POWERED TESTING, MOTION, OR ENERGIZATION**

This package contains 98 source-bound, 1:1, bed-normalized STL fit articles covering all twelve physical HR-30 modules, plus 22 generic 220 x 220 x 250 mm candidate plate layouts and twelve module ZIP bundles. Every transform is recorded in `fit-check-part-register.csv`; every mesh has minimum Z=0 mm and X/Y=5 mm. Use [index.html](index.html) for the interactive guide. Zero parts have been printed or accepted. No G-code or printer/slicer profile is released.
