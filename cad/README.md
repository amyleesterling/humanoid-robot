# CAD release area

Native parametric HR-V0 quote geometry now exists under [`hr-v0`](hr-v0/README.md). It generates four flat custom aluminum parts, neutral manufacturing files, readable SVG drawings, mass properties, and an assembly-space STEP/GLB model.

This is a **mechanical R0.1 preliminary baseline**, not a build release. The bracket fit coupon, hard stops, cable paths, covers, gripper, fixed shield, receiver fixture, final tolerance stack, fastener selections, bench anchors, proof calculations, and swept-volume validation remain release gates.

Manufacturer reference files and their provenance are separated under [`vendor`](vendor/robotis/README.md); they are not edited or silently treated as project manufacturing drawings.

**PRELIMINARY—NOT RELEASED FOR FABRICATION OR ENERGIZATION.**
