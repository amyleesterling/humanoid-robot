# HR-V0 Q4X box layout P0.1 CAD

PRELIMINARY - REVIEW PROXY ONLY - NOT APPROVED FOR FABRICATION OR DRILLING.

`build.py` creates a panel solid from Hammond catalog geometry plus a rectangular rail and component-envelope review assembly. The rail is not a profile-faithful part and the component blocks are not supplier CAD. The STEP/STL are collision and review proxies, not fabrication outputs. No rail fastener or gland hole is modeled because those coordinates remain SELECTION REQUIRED.
