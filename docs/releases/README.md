# Project Button release specifications

Document set revision: 0.1  
Status: draft engineering baselines; no release is approved for fabrication or operation

Each program gate has its own controlled release specification:

1. [HR-V0 bench arm](hr-v0.md)
2. [HR-30A active upper body](hr-30a.md)
3. [HR-30B supported full body](hr-30b.md)
4. [HR-30C powered stance](hr-30c.md)
5. [HR-30D tethered walking](hr-30d.md)
6. [HR-30W untethered walking](hr-30w.md)

A gate passes only when every mandatory entry condition, acceptance criterion, and evidence item in its specification has an approved record. Passing a later-looking assembly does not waive an earlier gate. None of these releases authorizes operation around children or the public.
