# Sol R12 status after R170

R170 narrows the compute-storage portion of Sol's architecture-only compute and safe-power-loss findings. It replaces an order-code-open storage branch with exact Kingston candidate `SDCIT2/64GBSP` and records manufacturer-stated power-failure, wear and monitoring features without treating them as system validation.

The design remains unready for imaging, powered test or energization. Exact received identity, Pi 5 compatibility, 64 GB endurance allocation, controlled image creation, filesystem policy, abrupt-loss fault injection, recovery, health monitoring, retention, current/thermal evidence and qualified review remain open.
