What changed

The AMC3330 input itself is high impedance, so this route can support a far lighter tap than the R176 2.25 mA industrial-input candidate. It still needs an engineered divider and protection network because AMC3330 accepts only ±1 V and TI says its EVM is not certified for high-voltage operation.
