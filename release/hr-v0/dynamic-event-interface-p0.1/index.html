Why it is still held

Each field input draws about 2.25 mA typical. That seemingly small load can matter on Pilz diagnostic pulses, monitored reset/start paths and EDM mirror-contact circuits. The taps remain prohibited until waveform comparison, fault injection and qualified noninterference review are complete.
