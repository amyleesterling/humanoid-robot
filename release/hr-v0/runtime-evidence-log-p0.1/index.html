The runtime now requires an evidence sink. A log-open or write failure prevents start or forces the active runtime through its existing heartbeat-removal and torque-off path. This is ordinary diagnostic evidence with zero functional-safety credit.

The committed host configuration still exits preflight. Calibration, clock behavior, storage policy, exact hashes, target HIL and authorization remain unresolved.
