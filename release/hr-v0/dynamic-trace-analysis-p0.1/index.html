Evidence flow

1. Common-clock raw trace
2. Integrity checks
3. Event edges
4. Time, travel and reset checks
5. HOLD for qualified disposition

What changed

The R78 channel plan now has an executable analysis contract. It detects stop, coil, mirror, rail and motion-stop events; verifies residual travel and endpoint clearance; and explicitly rejects reset-driven re-energization or motion before a separate start command.

The numeric values in the synthetic configuration test the algorithm only. Every physical-run value remains SELECTION REQUIRED.
