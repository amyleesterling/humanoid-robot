Gripper acquisition correction

HR-V0-GRIP-ACQ-P0.2 · 2026-08-08

The decision

ROBOTIS sells FR12-G101GM as a gripper frame set. It is useful evidence, but its published package scope does not establish the complete HR-V0 mechanism. It cannot silently replace the proposed RM-X52 parent kit.

RETAINED · NOT RELEASED

RM-X52

Current proposed parent kit for the enumerated mechanism subset.

Still requires received-content reconciliation, geometry, mass, H104 registration, fasteners, guarding and physical tests.

REJECTED AS SOLE SOURCE

FR12-G101GM

Exact SKU 903-0256-300. Published as a frame set with two named assemblies, bolts and spacer rings.

The published list does not establish the palms, linkages, rails, cable, complete mates or manufacturing definition needed by HR-V0.

SUPPLEMENT · HOLD

HN12-I101

Exact SKU 903-0240-000. ROBOTIS requires it for XM430 with the frame set; it is not included.

Received fit, mass, cable clearance, fastening and retention evidence remain open.

What remains open

This guide prevents an incomplete substitution. It does not make the gripper buildable.
