What “pinned” means

The manufacturer URL, release identity and manufacturer-published hash are recorded. It does not mean the project has downloaded or verified a local file.

What must happen before promotion

Authorized download, local hash, media write/readback, first-boot configuration, exact package manifest, hardening, inactive startup, power-loss recovery, rollback and signed controls/configuration review.

What is prohibited now

Do not download as a released build, write a project machine card, connect to actuators, run powered tests, or treat the image as an approved controls baseline.

Installation sequence — evidence checklist only

These checkboxes are local browser aids. They do not create evidence, approval or a signed record.
