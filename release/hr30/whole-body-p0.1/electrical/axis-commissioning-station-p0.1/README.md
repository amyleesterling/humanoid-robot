# HR-30 axis commissioning station P0.1

**PRELIMINARY - SUPPORT EQUIPMENT CANDIDATE - NOT APPROVED FOR CONNECTION, POWERED TESTING, MOTION, OR ENERGIZATION**

This support-equipment package gives the complete 25-axis HR-30 a controlled path to first electrical inspection without using the unreleased walking-power system. A Keysight E36313A candidate supplies one U2D2 Power Hub through one Mini-Fit input; exactly one disconnected actuator is attached with the matching ROBOTIS X3P or X4P cable. Candidate first power is 11.0 V with a 0.25 A current limit, read-only telemetry and Torque Enable read back as zero. Qualified approval, calibrated received hardware, restraint, executed inspection and a separately signed test authorization remain mandatory.
