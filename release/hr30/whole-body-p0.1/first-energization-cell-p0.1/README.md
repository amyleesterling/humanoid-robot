Editable source, STEP, GLB, dimensions, frame members, guards, restraint interfaces, stage use, instrument locations, BOM, sources, inspection traveler and open holds are included. The cell is unbuilt; FER-G02, G10 and G11 remain open, as do all other readiness gates and every work authority.
